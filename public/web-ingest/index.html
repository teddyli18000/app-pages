Personal transfer utility

web-ingest-drive

Move files from a public Baidu Netdisk share into your own Google Drive.

How it works

On request, GitHub Actions reads a public Baidu share and transfers its files into a dedicated Google Drive task folder. Google OAuth access is limited to files created by this application (drive.file).

This is a personal project, not a public file-transfer service. This website does not collect credentials or upload files.

Source & documentationPrivacy policy

Google account access

The application uses Google Drive access only for task folders and transferred files, including upload verification and resumption. Authentication is managed privately through GitHub Secrets, not through this website.
