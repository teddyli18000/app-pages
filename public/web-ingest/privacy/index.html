web-ingest-drive

Privacy Policy

Last updated: November 2026

This policy explains how web-ingest-drive, a personal Baidu Netdisk-to-Google Drive utility maintained by teddyli18000, processes transfer data.

Information accessed

  • Google Drive: after authorization, the app uses the drive.file scope to create task folders, upload requested files, and check metadata and integrity for files the app creates.
  • Baidu: the app reads the public share URL, extraction code (if required), selected files and source directory structure.
  • Task metadata: public share references, progress, file metadata and task IDs may be written to the public GitHub repository and Release control page.

Use of Google user data

Google Drive information is used only to perform, resume and verify the user-requested transfers. It is not sold, used for advertising, profiling, or AI training, or shared for unrelated purposes.

Storage and retention

  • OAuth credentials are held in private GitHub Actions Secrets and temporary runner files while operating. This website does not collect or store OAuth tokens.
  • Transferred files remain in the authorized Google Drive account until the account owner deletes them. Tool-owned Baidu staging copies can be cleaned after successful verification.
  • Public GitHub task metadata and commits may remain visible in repository history. Do not enter private links or personal data in the public task interface.
  • Google access can be revoked in the Google account's connected-app settings; stored secrets can be removed in GitHub repository settings.

Services involved

Transfers use Google Drive, Baidu Netdisk and GitHub Actions. Cloudflare hosts this information-only website and may process ordinary HTTP request information to deliver pages. No advertising networks or third-party tracking scripts are embedded on the site.

Contact and updates

For privacy questions, please contact the maintainer in the GitHub issue tracker. This page will be updated when the actual data practices change.

The use of Google user data is limited to the transfer functionality described here.
